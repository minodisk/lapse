# AGENTS.md

Instructions for AI coding agents working in this repository.

## Language

Write everything that becomes part of the repository or its public surface in **English**:

- Commit messages
- README and all other documentation
- Code comments
- GitHub Release notes, PR titles/descriptions, issue comments
- CLI output (help text, error messages, logs)

Conversation with the maintainer may be in Japanese, but anything committed or published must be in English.
